# Upgrade Report

UCL IHI upgrade report (MPhil to PhD), Luyuan Qi.

Build: `latexmk -pdf main.tex`

Outline notes appear in the PDF in italic quotes while drafting. Set `\drafttrue` to `\draftfalse` in `main.tex` to hide them.

## Writing style

- Use simple words. If a technical term is unavoidable, explain it the first time it appears.
- Simple sentence structure. One idea per sentence.
- Do not repeat what the report already said.
- No semicolons. No dashes as punctuation.
- Avoid the shape "A is B rather than C". Say what it is. If needed, say what it is not in its own sentence.
- Avoid unnecessary adjectives.
- Keep real technical terms exact (method names, dataset names, metrics).
